# Проект: «Закрывающий тег»

Это итоговый проект по курсу веб-вёрстки, который является не просто версткой макета, а рефлексией о пройденном пути обучения. Проект представляет собой одностраничный сайт-портфолио, где каждая из восьми карточек символизирует определенный этап, эмоции и трудности, с которыми пришлось столкнуться.

Главная особенность — интерактивность и внимание к деталям: две цветовые темы, сложные анимации, кастомные фильтры и персонализированный контент.

## Ключевые особенности и функциональность

*   **Две цветовые темы:** Светлая и тёмная темы, которые переключаются через меню. Стилизовано с помощью CSS-переменных.
*   **Адаптивная вёрстка:** Сайт корректно отображается на десктопных и мобильных устройствах.
*   **Комплексные анимации:**
    *   Интерактивная кнопка "лайка" в виде сердца с многоступенчатой анимацией на hover, active и click.
    *   Анимированные кнопки с эффектами при наведении и фокусе.
    *   Плавные переходы (`transition`) для всех интерактивных элементов.
*   **Интерактивность:**
    *   Модальное окно, реализованное с помощью тега `<dialog>`.
    *   Динамическая смена фавикона в зависимости от темы операционной системы.
*   **Продвинутые техники CSS:**
    *   Использование вариативных шрифтов.
    *   Сложные фоны, созданные с помощью `repeating-linear-gradient`.
    *   Режимы наложения `mix-blend-mode` для создания интересных визуальных эффектов.
    *   CSS-фильтры для уникальной стилизации изображений в карточках.
*   **Работа с SVG:**
    *   Использование SVG-спрайтов (`<symbol>`) для иконок.
    *   Инлайновая стилизация SVG для создания сложных анимаций.

## Использованные технологии и навыки

### HTML5 (Семантика)
- Семантическая вёрстка.
- Использование тега `<dialog>` для модальных окон.
- Работа с SVG (включая `<symbol>` и инлайновые стили).

### CSS3
- **Layout:** Flexbox, Grid Layout.
- **CSS-переменные:** для организации тем и управления стилями.
- **Типографика:** Подключение и использование вариативных шрифтов (`Inter`, `PressStart2P`), свойство `font-variation-settings`.
- **Анимации:** Продвинутая работа с `transition` и `@keyframes`.
- **Визуальные эффекты:** `mix-blend-mode`, `filter`, `text-stroke` с фоллбэком на `text-shadow`.
- **Адаптивность:** Использование `clamp()` и медиазапросов.
- **Кроссбраузерность:** Применение `@supports` для проверки поддержки свойств.

### Инструменты и практики
- **Git и GitHub:** Контроль версий и публикация проекта на GitHub Pages.
- **Figma:** Анализ макета.
- **Оптимизация:** Оптимизация изображений и SVG-графики.
- **Структура проекта:** Файловая структура по методологии БЭМ (Nested).
